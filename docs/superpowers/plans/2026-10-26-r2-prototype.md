# R2 球样与加工条件落实

用户已授权自主选择球样与样机加工条件，继续制作实际文件。

1. 将官方公开规格、项目选择、待测数据分别写入 data/r2_prototype.json。
2. 选择 AS-30 36 只、AS-10 24 只、MAVIS 350 12 只；为每只球预分配编号。实际批号、收货、尺寸和试验结果保持空白。
3. 为 44 主项确定首轮工艺路线；低速台架采用铝合金机加工，可换夹块采用 POM-C。未冻结安装接口不生成虚构孔型。
4. 从 data 中现有夹块几何导出四种半径、左右独立 STEP、正投影和剖面尺寸页；本轮夹块是无安装孔的试配毛件，不标作可直接装机零件。
5. 生成中文样本/加工说明、询价表、原始测量表和分阶段试验矩阵；检查实体回读、文件覆盖、PDF 排版和空证据状态。
6. 独立复核并修复，打包为 R2 补充交付。R1 原总装、动画和验证报告保持其原有范围。

边界：未采购、未联系加工厂、未测球、未加工或试验。全部未知实测值保持 null/空白。样本数量和试验次数是工程计划，不是容量或可靠性成绩。
