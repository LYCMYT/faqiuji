# R3 低速台架与可换夹块连接细化

用户要求把剩余工作继续做好。沿用已授权的自主选型/设计与文件制作，优先完成能由现有数据决定的机械连接。采用 executing-plans 连续执行，最终独立复核。

## 设计裁定
- R1总装保持基线。R3作为独立低速台架变体，所有新尺寸记入data/r3_fixture.json；不得假冒采购件孔型。
- 四个筒架落脚点采用宽垫块、上压板和两根M6穿透拉杆，避免在现有承载臂任意钻采购孔。
- 滑台支撑改为带上下盖板的矩形空心支柱、拉杆及侧压爪。把后/前支柱拉杆分别向行程外侧布置，检查释放悬臂全行程。
- 底板增加连接孔、支脚及台面锚固预留孔；支脚留螺母操作窗口，防止底板下螺母与台面相撞。
- 四种POM夹块增加两处沉孔，与独立铝托板穿透连接；托板自定义销孔是本机接口，不是执行器厂家孔型。执行器到托板连接仍待实际型号。为新紧固件真实开大分球侧壁通道并记录，不隐藏冲突。
- 标准件用可追溯外廓尺寸建模，螺纹按简化包络表达，牙型/强度/预紧力不由布尔无相交证明。

## 实施与验证
1. 写入data参数、孔表、连接合同与装配步骤。
2. 生成台架、紧固件、夹块连接变体，逐件STEP、总装、真实剖切、三视与孔位图。
3. 检查新件对现有件的静态和滑台/上夹/导套/下闸运动干涉；修正真正冲突。检查螺母扳手和沉孔工具通道。
4. 出具中文加工图集、BOM、检验表、修订记录与未决接口；生成BLEND/GLB和本地预览。
5. 重新打开文件、渲染检查、独立复核、修复并打包R3完整交付。
