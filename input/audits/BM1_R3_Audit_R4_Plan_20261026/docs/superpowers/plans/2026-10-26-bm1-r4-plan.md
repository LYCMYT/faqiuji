# BM1 R4 工程可靠性与低速台架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有R1–R3工程上修正可复现缺陷，建立不覆写输入、可追溯、失败即停止的构建与离线控制合同，并完成可评审的低速供球台架闭环设计。

**Architecture:** 权威设计、供应商/实测证据与派生产物分离；构建、检查、报告和打包共享同一构建标识。控制在动作前严格验证输入与持续不变量；机械按接球基准和五个低速运动功能完成导向、连接、限位与反力路径。

**Tech Stack:** 现有Python/CadQuery参数实体、JSON/CSV、Blender展示和本地查看器；Windows为现有完整构建基准。先检查并记录真实工具版本，不把仓库旧版本字符串当作当前测量值。

**Spec:** 当前仓库 README.md、README_DELIVERY.md、data/、docs/ 和 R1/R2/R3验收报告；本审查包 AUDIT_REPORT.md 与 evidence/。审查基准为 `c8c52514a80f52c364950852ed2fde2a1d926e62`。执行前检查HEAD；若已变化，先比对受影响问题，不覆盖他人更新。

**状态:** 本文件是尚待执行的计划；本次审查没有修改产品代码、采购或进行硬件试验。

## Global Constraints

- 保留44主项、ASM/PRT稳定编号及R1/R2/R3历史来源；派生实例数量可以随有记录的改进变化，不用硬编码旧189/155数量阻止合理设计。
- 保持现有右手坐标、mm/deg、H基准；R3低速台架局部height=0，不能当整机出球高度。
- 供球顺序保持：导套收回、托架脱筒、允许转头；释放早于牵引。当前理想切点约178.850448 mm不是实测捕获或制动位置。
- PRT-0402是俯仰短耳轴；PRT-0702是低位定位夹；PRT-0704是托球夹释放执行器；PRT-0903是配电与联锁箱。
- 输入和人工证据不得被日常构建覆盖；null保持未知，禁止把供应商确认、实测数值和制造放行补成虚构结果。
- 静态检查、指定离散运动、连续运动证明、装配约束、承载、实物性能分别报告。缺失检查用NOT_RUN/BLOCKED，不以空错误列表表示通过。
- 控制代码继续保持离线，真实硬件适配另设明确阶段；FAULT不自动复位，复位/重连不自动启动。
- 输出状态应按执行器功能定义，不把总enable=False冒充真实停止、保持或制动已经验证。
- 使用用户已有工程结构；以下新增模块名为约定，可在执行前与已有等效模块合并并记录，不能同时维护两套矛盾入口。

1. 修改design/parts/接触规则/生成器后复用旧PASS：任务3–4用来源失效和陈旧报告反例验证。

5. 给定球姿没有碰撞，但真实接触不能维持该姿态：任务7增加接触/支撑及小扰动检查，再安排任务8实物验证。
